# M3 Web app

- **Spec:** [web app](../specs/2026-10-07-web-app-design.md)
- **Branch:** `feat/m3-web`

**Goal:** from the laptop, see the runner live and work through the review inbox with the
keyboard only.

## Steps

### 1. Shell

- [ ] Layout route under `_authenticated`: sidebar (views + counts + projects), runner strip,
      main list area, right detail panel (URL-driven: `?ticket=NIW-12`).
- [ ] `copy.ts` with the Spanish UI strings.
- [ ] Use `convex/react` `useQuery`/`useMutation` directly (hub `convex/client-connection.md`).

### 2. Runner strip

- [ ] Subscribe to `web/runner:status`; render the six states (incl. `offline`).
- [ ] Client-side staleness: show `hung` styling when `lastHeartbeat` is older than 10 min even
      before the cron runs.
- [ ] Pause/resume control.

### 3. Lists

- [ ] Shared `TicketList` + `TicketRow` (36px, key mono, project chip, labels, PR/CI icons,
      size, +/- lines, time in status).
- [ ] Views: Por revisar (with "N por revisar" header and empty state), Cola, Atascados (inline
      question + reply box), Backlog.
- [ ] Keyboard hook: `j/k`, `Enter`, `o`, `m`, `c`, `x`, `s` (backlog → todo), `g r/q/s/b`;
      disabled while an input has focus. Test with Testing Library.
- [ ] After `m`/`c`/`x`: optimistic update and select the next row. Test.

### 4. Detail panel

- [ ] Inline edit of title, status, project, labels, priority, size.
- [ ] Spec section rendering acceptance criteria checkboxes; activity timeline; runs.
- [ ] Comment box.

### 5. Create and palette

- [ ] Quick create (`C`): title, project, optional body.
- [ ] `Cmd+K` palette: create, jump to view, search tickets.

### 6. Verify

- [ ] Seeded deployment: walk every view by keyboard; screenshot each for the PR.
- [ ] Session check happens before any data renders (no flash).

## Done when

The review inbox can be emptied with `j/k/o/m/c/x` alone on seeded data, the strip shows every
runner state (drive them with `heartbeat` calls from a script), `bun run verify` is green.

## After M3

Run the concept doc's design prompt with the `frontend-design` skill to produce `DESIGN.md`,
then a styling PR.
