# M6 Runner (post-MVP)

- **Spec:** [runner](../specs/2026-10-07-runner-design.md)
- **ADRs:** 0006
- **Branch:** `feat/m6-runner`

**Goal:** tickets in `todo` become PRs without anyone watching.

This plan is deliberately coarse: expand it after the MVP has run for a week, when real tickets
show what the agent session needs.

## Steps

- [ ] Verify the current Claude Code headless flags (`-p`, `--max-turns`, output format,
      permission/tool allowlist) and how rate limits surface; update the spec's open questions.
- [ ] `apps/runner`: config (runnerId, Convex URL, token, day/night windows, per-project
      overrides), lock file, `ConvexClient` subscription to `nextClaimable`.
- [ ] Worktree manager: create/reuse `<key>-<slug>` from `origin/<defaultBranch>`, copy env
      files, install, remove on `done`/`canceled`. Tests against a temp git repo.
- [ ] Agent step: prompt assembly (spec, criteria, `AGENTS.md`, reviewer comment on
      `changes`), run Claude Code, capture log to disk.
- [ ] Checks step: run `testCommand`; build the PR body with ticked criteria.
- [ ] PR step: push, `gh pr create` (draft on failed checks) or update the existing PR.
- [ ] Heartbeat loop (60 s) with step names; outcomes → `finishRun`, `agent-failed`,
      `needs-info`; attempt limit.
- [ ] Crash recovery: on start, find tickets claimed by this `runnerId` and resume or release.
- [ ] Service files for launchd and systemd; docs page "Run the runner".
- [ ] Trial: one week on one low-risk repo; measure tickets closed unattended (the ADR 0001
      success condition).

## Done when

Over the trial week the runner closes tickets end to end without supervision and every failure
shows up in the stuck view with a reason.
